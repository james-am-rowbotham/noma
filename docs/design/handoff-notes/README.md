# Handoff notes

Design updates that arrived as **text** rather than as a bundle, kept verbatim so they are not lost
before they are assimilated. Each is dated by when it was received.

These are input, not specification. Once a note's content is in
[`../explorer.md`](../explorer.md) or its own spec — and its measurements are in code held by tests —
the note goes, along with this directory.
